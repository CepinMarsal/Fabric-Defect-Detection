Computer Vision Project

Fabric Defect Detection using Computer Vision

Deskripsi Proyek

Proyek ini mengembangkan sistem deteksi cacat kain menggunakan teknologi Computer Vision. Sistem mampu mengidentifikasi berbagai jenis cacat pada permukaan kain secara real-time melalui kamera.

Tujuan

Membangun sistem inspeksi visual otomatis yang dapat membantu proses quality control pada industri tekstil, meningkatkan efisiensi dan akurasi deteksi cacat kain.

Teknologi

Menggunakan teknik Image Processing, Edge Detection, Feature Extraction, dan algoritma klasifikasi untuk mendeteksi serta mengklasifikasikan jenis cacat pada kain.

Manfaat

Mengurangi biaya inspeksi manual, mempercepat proses quality control, dan meningkatkan konsistensi hasil inspeksi pada proses produksi tekstil.
